# Easy Long AI Play (ELAP)

Динамическая карточка и инжектор промптов для SillyTavern.

## Установка в SillyTavern

### Способ 1. По ссылке на репозиторий (ПК и телефон)
1. Откройте SillyTavern.
2. Перейдите в меню **Расширения** (иконка пазла в верхней панели).
3. Нажмите **«Установить расширение»** (Install Extension).
4. Вставьте ссылку на репозиторий:
   ```
   https://github.com/Luci-GH/ELAP
   ```
5. Нажмите **Сохранить** (Save) и перезагрузите страницу SillyTavern.

### Способ 2. Вручную через Git / ZIP
1. Склонируйте репозиторий в папку:
   `public/scripts/extensions/third-party/elap/`
2. Перезапустите SillyTavern или обновите страницу.

## Использование

1. Добавьте тег `{{ELAP}}` в любую часть карточки персонажа (например, в Post-History Instructions, System Prompt или Main Prompt).
2. В панели расширения ELAP настройте нужные блоки состояния, таймлайн и директивы.
3. При генерации сообщений тег автоматически наполняется актуальным контекстом сцены, а агент актуализирует состояние.
